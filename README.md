# PrepBuddy (prototype website)

A phone-first practice site for HKDSE-style Biology questions: Quick 10, weak-topic practice, a timed mini mock, MCQs, written answers marked against a mark scheme, and diagram labelling.

- Everything is in `index.html` (questions are built in). Progress is saved in the browser on each device.
- Hosted on Vercel at https://prepbuddy.givingtree.sg
- Source text for the questions: OpenStax Biology 2e (CC BY-NC-SA 4.0). Access for free at openstax.org. Non-commercial use only.
